as much as possible, i strongly prefer for the content of the apps that we are
working on to fit on the first visible portion of the screen that the user gets
to when they first enter that section of the app. so the contents of the
application should fit on one screen unless otherwise stated. this means that if
it is on pc, it will all fit on the pc sized screen. if they are on mobile, then
it should all fit into the first screen. this means that the user shouldn't have
to scroll down to see the contents of the app. this is true for all screen
sizes. if they should happen to run out of room in the screen, then the side
scroll bar can appear which allows them to see the rest of the contents of the
page.
